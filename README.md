# sammyjankis19302.github.io

The personal website of Akula Uday Kiran, aerospace engineering student at RV College of Engineering,
Bengaluru: **[sammyjankis19302.github.io](https://sammyjankis19302.github.io)**.

It is plain HTML, CSS and JavaScript, served by GitHub Pages, with no frameworks and no trackers.
The figure at the top is computed in the visitor's browser: potential flow past a Joukowski
aerofoil, with the circulation set by the Kutta condition (`assets/site.js`).

## Updating it

All the text is in [`src/content.py`](src/content.py). Change it there, then rebuild:

```bash
python3 src/build.py
```

That rewrites `index.html`, `404.html`, `sitemap.xml` and `robots.txt`, using only the Python
standard library. New images go in `assets/img/` as WebP files. Commit and push, and GitHub Pages
publishes the change within a few minutes.

## Layout

```
index.html, 404.html     the pages (generated by src/build.py)
assets/site.css          styles, light and dark
assets/site.js           theme switch and the live flow figure
assets/fonts/            B612 and Source Serif 4 (SIL Open Font License)
assets/img/              figures and photos
src/content.py           every word on the site
src/build.py             the generator
og.png                   the picture shown when the link is shared
```
